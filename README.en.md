## About the Project

LeitorSEFAZ was developed to automate the process of querying electronic invoices through the SEFAZ-PE portal and recording the information in an Excel spreadsheet, reducing the need for manual data entry.

## Features

- QR Code scanning using the camera.
- Manual entry of the access key or input via QR Code.
- Automatic invoice queries through SEFAZ-PE.
- Automatic data storage in an Excel spreadsheet.
- Support for multiple browsers: Firefox, Chrome, and Edge.

## Installation for Development

### Clone the repository

```powershell
git clone https://github.com/devlucaass/LeitorSEFAZ.git

cd LeitorSEFAZ
```

### Create a virtual environment

```powershell
python -m venv venv
```

### Activate the virtual environment (PowerShell)

```powershell
.\venv\Scripts\Activate.ps1
```

### Install dependencies

```powershell
pip install -r requirements.txt
```

### Run the project

```powershell
python src/main.py
```

## Executable for Development

LeitorSEFAZ can also be built as a Windows executable using PyInstaller.

### Install PyInstaller

With the virtual environment activated, run:

```powershell
pip install pyinstaller
```

The project includes a specific configuration file for the build process:

```text
LeitorSEFAZ.spec
```

### Build the executable

Run:

```powershell
pyinstaller LeitorSEFAZ.spec
```

The files generated by PyInstaller will be stored in the `build/` and `dist/` directories.

The `build/` directory contains temporary files used during the build process, while `dist/` contains the executable and the files required to run it.

## Usage

1. Open the application.

2. Generate a spreadsheet template using the "Gerar modelo da planilha" button.

3. Save the spreadsheet template wherever you prefer.

4. Open the settings.

5. Click "Localizar planilha" and select the spreadsheet template.

6. Choose the browser you want to use (Firefox, Chrome, or Edge).

7. Save the settings and close the window.

8. Enter the cell from which you want to start.

9. Choose how to provide the access key:

   - **QR Code**: click "Ler QRCode" and point the camera at the invoice's QR Code. No CAPTCHA is required.

   - **Manual**: enter the access key in the field and click "Iniciar". You will need to solve the website's CAPTCHA.

10. Wait for the spreadsheet to open automatically or keep the spreadsheet template open.
